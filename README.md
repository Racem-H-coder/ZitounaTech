Comprehensive enterprise management system tailored for the agricultural and olive oil processing sector.

## Features
- **Human Resources & Workforce Planning:** Employee records, leave approvals, shifts, and attendance KPI dashboards.
- **Inventory & Equipment:** Real-time stock alerts, equipment lifecycle and maintenance scheduling.
- **Financial Invoicing:** Automated invoicing, dynamic tax rates, and QR-code certified receipts.
- **Hardware Security Bridge:** Arduino serial interface for Keypad PIN security and biometric fingerprint verification.
- **AI Assistants:** Integrated LLM clients for procurement recommendations and financial trend analysis.
